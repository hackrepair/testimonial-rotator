# Support and maintenance scope

Future updates are unlikely. This project is limited to security and PHP-version maintenance, with no commitment to new features, regular releases, or continuing support.

Use GitHub Issues for reproducible development defects, Discussions for general questions, and https://hackrepair.com/ for maintenance contact. Security reports must follow SECURITY.md.

Include WordPress/PHP/plugin versions, theme, shortcode/widget configuration, reproduction steps, expected/actual behavior, and redacted error messages. Do not upload live databases, credentials, or customer testimonials without permission.

No production-ready 4.0 release is promised by the development archive. Always back up and validate on staging.
