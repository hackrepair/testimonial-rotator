# Security policy

## Status
Version 4.0 is a development candidate. The original plugin was closed on WordPress.org for a security issue; the specific applicable advisory and broader code paths remain under review. This repository does not claim all historical vulnerabilities have been resolved.

## Private reporting
Email **jim@hackrepair.com** with subject **Testimonial Rotator (Reborn) security report**. Include affected version, role/permissions, reproduction steps on a disposable site, impact, and a minimal proof of the issue. Remove credentials and private data.

Do not post working exploits, private logs, or customer data in public issues. Allow time for assessment before disclosure. There is no guaranteed response time, bounty, or future security-update commitment. Future updates are unlikely; site owners remain responsible for assessing deployment risk and alternatives.

Do not probe sites you do not own or have permission to test. Use disposable local fixtures for verification.
