Renew the foundation.

The original Testimonial Rotator gave site owners a straightforward way to manage customer praise. Then development stopped, its website was abandoned years ago, and documentation links broke.

I am Jim Walker, The Hack Repair Guy. I am taking over maintenance of this independent continuation to bring the aging code forward for PHP 8.3 while preserving useful content and familiar integrations.

Hal Gatewood remains credited as the original author. Reborn is an unofficial continuation, not an endorsement or an official reopening of the old WordPress.org listing.

Familiar where it matters.

  • Existing testimonials and rotator relationships
  • Original widget identity and shortcode aliases
  • Seven bundled display templates
  • Ratings, author fields, images, and excerpts
  • Local, current View details information

Modernization with evidence.

Maintenance repairs stored-XSS output paths, adds metadata-save request checks, confines template selection, normalizes widget inputs and fixes aggregate ratings. Repository checks exercise syntax, local details content, ZIP packaging, and WordPress fixtures.

Passing those checks does not prove every historical security issue is fixed. The declared target is WordPress 7.1; see the validation guide for exact fixture versions and coverage.
