# History and source provenance

Hal Gatewood created the original Testimonial Rotator. It added widgets, shortcode displays, ratings, author fields, rotator controls, and template support over its lifetime. Version 3.0 merged the separate theme pack. The final numbered upstream tag found was 3.0.3, dated June 15, 2020 in its changelog.

The original website was abandoned years ago. The WordPress.org listing records closure on February 25, 2021 for a security issue: https://wordpress.org/plugins/testimonial-rotator/. That closure is not evidence of a particular completed fix in Reborn.

The preserved source was exported on November 6, 2026 from https://plugins.svn.wordpress.org/testimonial-rotator/trunk/ at repository revision 3788813. Trunk's last-changed revision was 2506179 (March 30, 2021). Its readme selected trunk as stable. The locally preserved upstream ZIP has SHA-256 `38810c46d76fab196e40b59fda46c31d6676bed0c417a8d2924fe4ba8f337415`.

In November 2026, Jim Walker, The Hack Repair Guy, began an unofficial 4.0 maintenance continuation for security and PHP-version compatibility. Original author credit is preserved as plain text, without a link to the abandoned website. No official endorsement, transfer, or WordPress.org reopening is claimed.

Reborn's repository publication and any future release are separate events. See CHANGELOG.md and GitHub Releases for actual published release status. Future updates are unlikely.
